# flous-data

[![Validate](https://github.com/Flous-it/flous-data/actions/workflows/pr-validate.yml/badge.svg)](https://github.com/Flous-it/flous-data/actions/workflows/pr-validate.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)
[![PRs welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](./CONTRIBUTING.md)

**Open, community-maintained dataset of Italian banks and their financial
products** — current accounts today; deposits, mortgages and cards over time.
It's the source of truth behind [flous.it](https://flous.it).

The data is authored as **YAML**, validated against typed schemas, and built into
distributable artifacts. It is distributed through **one channel: a CDN**
(Cloudflare R2, served at `data.flous.it`).

```
data/banks/*.yaml      ─┐
data/accounts/*.yaml    ├─ scripts/build.py ─► dist/flous-data.json   (→ CDN: data.flous.it/v1/dump.json)
data/features.yaml     ─┘                    ─► dist/flous.sqlite     (→ CDN: data.flous.it/v1/flous.sqlite)
                                              ─► dist/types.ts
```

> **`data/` is the source of truth.** Everything in `dist/` is generated by
> `scripts/build.py` and git-ignored — never edit it by hand.

## Using the data

The dataset is public. Fetch the latest build straight from the CDN:

| Artifact | URL |
|----------|-----|
| Full JSON dump | `https://data.flous.it/v1/dump.json` |
| SQLite database | `https://data.flous.it/v1/flous.sqlite` |

```bash
curl https://data.flous.it/v1/dump.json | jq '.banks[].name'
```

The JSON shape is documented by the generated TypeScript types in
`dist/types.ts` (`FlousDataDump`). Each dump carries a `version` and `built_at`
so you can detect changes.

**Who consumes it internally:** `flous-api` fetches from the CDN and runs the
bank-comparison logic; `flous-web` calls `flous-api` only and never reads the CDN
directly.

## Contributing

**Contributions are very welcome — you don't need to be a programmer.** If you
can read a bank's fee sheet and edit a text file, you can help keep the data
accurate.

- 🐞 Found wrong data? → open a [Data correction issue](https://github.com/Flous-it/flous-data/issues/new/choose).
- 🏦 Want a bank/account added? → open an issue or send a PR.
- 🛠️ Want to improve the tooling? → PRs welcome.

👉 **Start with [CONTRIBUTING.md](./CONTRIBUTING.md)** — it explains the data
model, how to add a bank/account/feature, sourcing standards, and the PR
workflow. Please also read our [Code of Conduct](./CODE_OF_CONDUCT.md).

### Workflow at a glance

`main` is protected: **all changes land through Pull Requests** that pass CI
(`validate.py` + `ruff` + `mypy`). Direct pushes to `main` are disabled. Fork →
branch → PR → review → squash-merge → auto-publish to the CDN.

## Local development

Requires **Python 3.12+**.

```bash
git clone https://github.com/Flous-it/flous-data.git
cd flous-data
python3.12 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

python scripts/validate.py   # validate YAML schemas + cross-references (CI)
python scripts/build.py      # build dist/ artifacts locally
ruff check schemas/ scripts/ # lint
mypy schemas/ scripts/       # type-check
pytest                       # tests
```

## Data model

| Type | File(s) | Schema | Description |
|------|---------|--------|-------------|
| **Bank** | `data/banks/<slug>.yaml` | `schemas/bank.py` | Issuer: name, slug, BIC, ABI, MEC code. |
| **Account** | `data/accounts/<slug>.yaml` | `schemas/account.py` | A product belonging to a bank, with its feature values. |
| **Feature** | `data/features.yaml` | `schemas/feature.py` | The catalog of comparable attributes (e.g. `monthly_fee`). |

Feature values are polymorphic: each feature declares a `value_type`
(`boolean`, `money_fixed`, `money_with_quota`, `percentage`, `text`), which
determines how accounts populate it. Conditional pricing (e.g. *free with salary
credit*) is modelled per feature. See
[CONTRIBUTING.md](./CONTRIBUTING.md#adding-or-editing-data) for the full
reference and examples.

## Publishing & versioning

On merge to `main`, CI rebuilds the artifacts, uploads them to Cloudflare R2
(`data.flous.it/v1/`), and pings `flous-api` to refresh. See
`.github/workflows/build-publish.yml`. Required GitHub secrets:
`R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_ENDPOINT`, and (optional)
`FLOUS_WEBHOOK_URL` / `FLOUS_WEBHOOK_SECRET`.

The dataset follows [Semantic Versioning](https://semver.org/) (`version` in
`pyproject.toml`, embedded in `dump.json`). Changes are tracked in
[CHANGELOG.md](./CHANGELOG.md).
